# Number Guessing Game 🎯

## About
A Python-based number guessing game with three difficulty levels
and personalized user interaction.

## Features
- Personalized welcome message
- Easy, Moderate and Hard difficulty levels
- Different number ranges for each difficulty
- Limited attempts
- Higher/lower hints
- Replay option

## Difficulty Levels
__________________________________
|   Level  |   Range  | Attempts |
|----------|----------|----------|
| Easy     | 0 to 50  |    5     |
| Moderate | 0 to 100 |    10    |
| Hard     | 0 to 500 |    15    |

## Technologies
- Python
- random
- time

## How to Run
